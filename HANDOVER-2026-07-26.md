## 1. What the experiment is

LLM agents play 6-power Diplomacy as three blocs of two non-adjacent powers. Every agent is a
ruthless supply-centre maximiser carrying a **latent moral constitution** (utilitarian /
deontological / retributive) that binds only when a rival invokes it via `compel_action` and
an LLM arbiter rules it applies. Question: **which moral framework is least exploitable when
rivals know you have it?**

Vehicle, models and frozen design: see `EXPERIMENT-PROTOCOL.md`. Core code: `orchestrator.py`
(game loop), `agent.py` (per-bloc thread), `frameworks.py` (constitutions + system prompt),
`facts.py` (the shared moral record), `judge.py` (the arbiter), `tools/`, `state.py`.

## 2. What happened in this session (2026-07-25 → 26)

Brodie asked for a fairness audit before committing ~USD 100, specifically: *is
`compel_action` fair, or does some framework have an easy defence coming from the fact pool /
rubric / mechanics rather than from its doctrine?*

**The standard applied** (worth keeping — it resolves the apparent paradox in the request):
"no framework should have an easy defence" cannot mean *equalise defences*, because
differential defensibility IS the dependent variable. The operative test is: a framework may
be hard to compel **only because of its moral structure**, never because of the substrate,
the rubric wording, the tool mechanics, the prompt examples, or a measurement bug.

Audit is in `AUDIT-2026-07-25-compulsion-fairness.md` (148 proposals, 13 pilot games).
Decisions D34–D37 record what changed and why. Headline: the pilot ordering
(ret 27% > deon 11% > util 10%) was **partly artifact** — seat explained as much variance as
framework, and denominator junk alone moved deontological by 9 points.

### Changes made (all committed, all verified)

- **D34 — Tier-1 correctness + real enforcement.** `compel_action` now validates that the
  demand is a legal order the target can actually issue (14% of pilot demands named a unit
  the target didn't own); the arbiter sees defender-cited facts, attributed by source; fact
  lookup understands 3-letter province codes (41% of pilot proposals named a fact territory
  only by code); conflicting binds resolved deterministically; arbiter gets real board
  context; rubric rule 3 de-staled and made symmetric; JSON parse hardened; negotiation order
  seeded. A COMPELLED order is now **written into the engine**, with a guard against the bloc
  self-bouncing it. Utilitarian gained a prohibitive clause (it was the only framework stated
  purely as a positive duty — which is why all six positive-welfare facts were never cited).
- **D35 — fact-pool parity.** Pool 28 → 33. Every framework now has a positionally-actionable
  trigger on all 6 powers: +2 utilitarian transit facts (`NORTH SEA.0`, `SERBIA.1`), +3
  deontological territorial pacts (`BELGIUM.1`, `TYROLIA.0`, `GALICIA.1`). Removed the
  "this season" expiry clause, which sat on exactly the two facts giving utilitarian a causal

## 4. Interpretation traps — I fell into all of these, do not repeat them

**These cost real time and produced three wrong conclusions I had to retract in front of
Brodie. They are the most valuable content in this file.**

1. **Do not generalise from one examined case.** I read one bind in detail, built a story,
   and applied it to all six — three separate times (rule 6, the "clever concession", and
   "zero forced binds = inert"). Every time, checking the other cases refuted it. Always run
   the check across the whole set before asserting a pattern.

2. **`enforced=False` does NOT mean the bind did nothing.** The override only fires when an
   agent **defies** a ruling it was told is binding (`SHARED_OBJECTIVE`: "you MUST comply").
   An agent that complies is the mechanic *succeeding*. Zero forced binds = zero defiance,
   which is the hoped-for outcome.

3. **The real DV is the bind-quality split, not bind rate** (D37, now computed by the audit
   skill, §6b):
   - **lock-in** — target had already announced the move; the compulsion made it enforceable
     against a rival licensed to lie, but changed no intention;
   - **new behaviour** — target had not announced it and then did it; the compulsion
     plausibly changed what happened;
   - **defiance** — `enforced=True`; target resisted and was overridden. Zero so far.
   showcase1 through year 3: **4 new behaviour, 2 lock-in, 0 defiance.**

4. **Agents are NOT bind-maximisers.** Their only objective is combined bloc supply centres.
   Bind rate is *our* measure, not their incentive. Do not explain agent behaviour by
   appealing to it.

5. **Compulsion is being used as a commitment device** (D36), not only as a weapon. Austria's
   own words before a `compel_action` call: *"Now lock Germany into attacking France — they
   already said they'd do it, but let's bind it."* Deception is explicitly licensed, so an
   arbiter-upheld compulsion converts cheap talk into an obligation. The design never
   specified this use.

6. **Verify negatives against the repository, not the working tree.** I reported that
   decision D33 "does not exist" on the strength of a clean `grep`. It existed — local `main`
   was 5 commits behind `origin/main`. `git fetch` and check `git log origin/main ^main`
   before claiming anything is missing. This is now a rule in `CLAUDE.md`.

7. **Seat rivals framework as an explanation.** Bind rate by target *power* has ranged 3%–40%.
   The three deep games form a Latin square so seat is *balanced*, but at n=1 per cell it is
   not *controlled*. Never report the framework ordering without saying so.
